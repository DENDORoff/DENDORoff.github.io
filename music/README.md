# music/

Положи сюда свои треки (`.mp3`) — плеер на странице сам найдёт файлы
через GitHub API и добавит их в плейлист.

Как добавить:

1. GitHub → репозиторий `DENDORoff/DENDORoff.github.io` → **Add file → Upload files**
2. Перетащи MP3 в папку `music/`
3. Commit — GitHub Pages пересоберёт сайт (~1 минута), треки появятся в плеере

Рекомендации:

- Имя файла `Название - Артист.mp3` — запасной вариант, если в файле нет ID3-тегов.
- Название, артист, альбом и **обложка** читаются из ID3-тегов файла
  (проверить можно: ПКМ по файлу → Свойства →Подробности).
- Файлы должны лежать прямо в `music/` (без подпапок).
- Вес: до ~50 МБ на файл без предупреждений Git.

Плеер: ▶ пауза, `|<` `>|` переключение, клик по таймлайну — перемотка,
ползунок — громкость, **пробел** — play/pause, весь плейлист крутится по кругу.
В верхней панели — компактный мини-плеер: кнопки + полоса прогресса.
